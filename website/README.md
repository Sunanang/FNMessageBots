# FnMessageBots 官网

单文件静态站点：`index.html` + `assets/`，**零依赖、零构建**（与 `jiadi/website` 同一套做法）。

## 本地预览

```bash
cd website && python3 -m http.server 8081
# http://127.0.0.1:8081
```

## 部署

线上地址 `https://www.fnmb.lndo.top`（`fnmb.lndo.top` 用 DNSPod 显性 URL 301 到 www）。

EdgeOne Makers 新建项目指向本目录即可（纯静态，无需构建命令、无需 node）。

## 设计约定

方向：**机房夜间值班台**。底色是偏绿的墨黑（`#080B0A`），文字三级，**一个琥珀主色**（`#E0A33E`），
绿色只表示「已送达」这一种含义。全站深色单主题，不使用渐变文字、发光、彩色阴影或 emoji。

- 首屏是这套设计的亮面：一个**真的在跑**的轮询控制台——日志逐条流入 → 变暗退到背景 → 汇总卡片出现 →
  9 个渠道小点依次点亮 → 右侧进度条走向下一轮，约 6 秒一个循环。
  `prefers-reduced-motion: reduce` 下直接停在终态，不循环。
- 其余部分刻意安静：对照表、管道图、渠道清单 + 同一条消息在四种渠道的排版、配置面板、两段安装命令、FAQ。
- 页内所有「画面」都是 HTML/CSS 手写，不用截图——缩放不糊字，改文案不用重出图。
- 两段内联脚本：循环演示 + 管道进度线的 IntersectionObserver。无第三方依赖。
- 页脚必须有 `京ICP备2026075277号-1` 并链接 `https://beian.miit.gov.cn/`。
- 手机端（≤600px）导航收进右上角菜单；对照表改为「一个情形一块」的堆叠，不再挤三列。
