# MeoW 推送

[← 推送渠道总览](../notification-channels.md) · [← README](../../README.md)

[MeoW](https://www.chuckfang.com/MeoW/api_doc.html) 是一款手机推送 App，只需一个昵称即可接收通知。

<span style="color: #c62828;"><strong>注意：请仔细核对昵称。MeoW 规定同一 IP 一天内累计 3 次推送到未注册的昵称会被封禁。本应用在收到「昵称未注册」后会暂停向该昵称推送，修改昵称并保存配置后恢复。</strong></span>

## 一、准备工作

1. 在手机上安装 MeoW App 并注册一个昵称。
2. 记下该昵称（不能包含斜杠）。

## 二、在本项目中配置

**方式 A：Web 配置页**

1. 添加推送渠道，类型选择 **MeoW**，填写 **昵称** 即可。
2. 如需点击通知后打开 NAS 页面，可展开 **高级选项** 填写 **跳转链接**。
3. 保存后在页面底部「发送测试」验证。

**方式 B：`config.json` / 环境变量**

配置项 `meow_params`（环境变量 `MEOW_PARAMS`），值为 JSON 字符串，多个昵称用 `|` 分隔：

```json
{"nickname": "你的昵称", "url": "http://192.168.1.10:5666"}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `nickname` | 是 | MeoW App 中注册的昵称 |
| `url` | 否 | 点击通知跳转的链接 |
| `api_base` | 否 | API 地址，默认 `https://api.chuckfang.com` |

## 三、频率限制与常见问题

- 非会员发送上限：3 秒 1 条、每分钟 15 条、每小时 60 条、每天 1000 条，超出返回 `429`。事件较多时建议开启「轮询汇总模式」，把短时间内的多条事件合并为一条。
- `404` 昵称未注册：检查昵称拼写，确认已在 App 中注册。
- `403` 内容策略禁止发送：消息内容被 MeoW 拦截。
- 尽量不要通过多人共享的公共出口 IP 推送，可能被 MeoW 判定为攻击。
