# SMTP 邮件（邮箱通知）

[← 推送渠道总览](../notification-channels.md) · [← README](../../README.md)

通过邮箱服务商的 **SMTP** 将告警发到指定收件箱。与 Webhook 类渠道不同，你需要在邮箱里开启 SMTP / 发信服务，并通常使用 **授权码**（或应用专用密码），而不是网页登录密码。

<span style="color: #c62828;"><strong>注意：邮件账号与授权信息属于敏感数据，请勿截图外传或提交到公开仓库。</strong></span>

## 一、准备工作（在邮箱侧）

1. 登录你常用的邮箱网页端或官方 App，找到 **SMTP / POP3 / IMAP** 或「客户端授权」相关设置。
2. 按服务商说明 **开启 SMTP 发信**，并生成 **授权码**（QQ、163、Outlook 等常见邮箱多采用授权码；部分企业邮箱由管理员统一开通）。
3. 记下服务商提供的 **SMTP 服务器域名** 与推荐 **端口**（常见为 `465` 或 `587`）。

## 二、在本项目中配置

**方式 A：Web 配置页**

1. 打开应用配置页面，添加推送渠道 **SMTP 邮件**。
2. 依次填写：**SMTP 服务器**、**端口**、**用户名（一般为完整邮箱地址）**、**密码（多为授权码）**、**发件人显示**（可选）、**收件人**（多个地址用英文逗号分隔）。
3. 保存配置。

**方式 B：`config.json`**

在同文件中维护 `smtp_params` 字段，值为 **一段 JSON 字符串**（格式见下文）。

**方式 C：环境变量**

设置 `SMTP_PARAMS`，值为与 `smtp_params` 相同的 JSON 字符串。环境变量优先生效，规则与其它渠道一致，详见 [推送渠道总览](../notification-channels.md)。

## 三、`smtp_params` JSON 字段说明

保存到配置或环境变量时，**单个邮箱渠道**对应一个 JSON 对象，例如：

```json
{
  "server": "smtp.qq.com",
  "port": 465,
  "username": "yourname@qq.com",
  "password": "邮箱SMTP授权码",
  "from": "飞牛告警",
  "to": "receiver@example.com,backup@example.com"
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `server` | 是 | SMTP 服务器主机名，如 `smtp.qq.com`。 |
| `port` | 否 | 端口；未填写时默认为 **465**。 |
| `username` | 是 | 通常为你的完整邮箱地址（登录 SMTP 的账号）。 |
| `password` | 是 | 一般为服务商提供的 **授权码** 或应用密码，而非网页登录密码。 |
| `to` | 是 | 收件人；多个地址用英文 **逗号** 分隔。 |
| `from` | 否 | 显示的发件人；留空则使用 `username`。若填写内容 **不含 `@`**，程序会将其作为「昵称」，与登录邮箱组合显示。 |

**多套 SMTP（多个发信账号或多条规则）**：与 PushPlus 等渠道相同，可将多段 JSON 用 **竖线 `|`** 连接成一行字符串，例如：`{"server":"...","username":"..."}|{"server":"..."}`。

## 四、端口与加密方式（程序行为）

程序会根据端口自动选择连接方式（无需在 JSON 里额外开关）：

- **端口为 465**：使用 **SMTP_SSL**（implicit TLS）。
- **其它端口**：使用明文连接后 **STARTTLS**（常见于 **587**）。

若你的服务商要求必须使用 **587 + STARTTLS**，请将 `port` 设为 `587`；若推荐 **465 SSL**，则设为 `465`。

## 五、常见服务商参考（请以官网最新说明为准）

以下仅供快速对照，具体以各邮箱「客户端设置」页面为准：

| 服务商 | SMTP 服务器（示例） | 常用端口 |
| --- | --- | --- |
| QQ 邮箱 | `smtp.qq.com` | 465 或 587 |
| 网易 163 | `smtp.163.com` | 465 或 587 |
| Outlook / Microsoft 365 | `smtp.office365.com` 或 `smtp-mail.outlook.com` | 587 |
| Gmail | `smtp.gmail.com` | 587（需应用专用密码或 OAuth，本项目按用户名密码登录） |

发送失败时，请优先核对：**授权码是否最新**、**端口与服务商要求是否一致**、**是否需在服务商侧开启「允许不太安全的应用」或单独开启 SMTP**。
